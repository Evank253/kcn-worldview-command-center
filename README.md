## Official Quality Gate

**kcn-preflight** replaces the old “vibe coder / vibe developer” concept.

It is a real, inspectable pre-push pipeline that:
- Auto-fixes formatting (black / prettier / gofmt)
- Blocks on real secrets
- Runs real linters & security scanners
- Generates CI workflows and shields.io badges
- Gives a clear PASS / BLOCK verdict

Every KCN system should run `preflight check .` before pushing.

This aligns with the **KCN Assurance Protocol (KAP)** governance standard.
