# KCN Worldview

**Status**: Scaffolding  
**Type**: Independent system

## Purpose
Intelligence and knowledge-graph platform.  
Multi-source data fusion, entity relationships, interactive globe, and research tools.

Inspired by public recreations of Palantir-style command centers (e.g. Bilawal Sidhu’s WorldView, World Monitor) while remaining a fully original KCN system.

## Core Features (planned)
- Interactive 3D / flat globe
- Knowledge graph (people, places, organizations, events, concepts)
- Multi-source live data layers
- Entity search & relationship explorer
- AI reasoning / summarization panel
- Ability to receive cyber events from Cyber Security HQ as a layer

## Tech Direction
- Frontend: React / Next.js + MapLibre GL or Cesium / globe.gl
- Graph store: Neo4j or lightweight in-memory graph for early versions
- Data: Public APIs + curated feeds

## Owner Access
Fully free and unrestricted.
